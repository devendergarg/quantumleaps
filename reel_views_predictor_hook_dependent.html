About the model

Like Rate is intentionally excluded. The model uses Hook Rate and Share Rate only. The coefficients come from the current 5-coefficient model selected for low-view Reel prediction. Validation was performed using leave-one-out cross-validation on the 26-Reel dataset, with the ≤300K-view Reels as the primary evaluation group.
